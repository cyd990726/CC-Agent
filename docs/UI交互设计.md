# UI 交互边界与验证

交互模式由一个 `prompt_toolkit.Application` 独占终端。布局从上到下是
可滚动记录、独立 activity 行、输入框、命令补全、footer。权限确认时，
底部切换为审批选项；输入草稿保留，完整命令和修改预览写入上方记录供翻阅。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `agent/events.py` | 运行时事件，不包含终端绘制逻辑 |
| `ui/renderer.py` | 将事件转换为稳定输出块与活动状态；交互模式输出交给 TerminalApp |
| `ui/transcript.py` | 保存渲染内容快照，按当前终端宽度缓存 Markdown/表格排版 |
| `ui/selection.py` | 输出选区高亮、选择期间的内容快照和系统剪贴板写入 |
| `ui/terminal.py` | 输入、任务队列、窗口布局、滚动位置、审批调度与关闭生命周期 |
| `ui/permissions.py` | 权限决策、完整操作预览；支持独立和统一 UI 两种入口 |

参考 Claude Code 的 `FullscreenLayout.tsx`、`ScrollKeybindingHandler.tsx`
和 `useVirtualScroll.ts`：滚动记录与固定底部独立，跟随最新内容是明确状态，
滚动按屏幕行处理。这里保留 Python 实现，没有引入 React/Ink 或虚拟列表。

## 交互约定

- 输入期间后台任务可继续执行；新的普通输入按队列顺序运行。
- Enter 提交；Alt+Enter/Ctrl+J 换行。命令补全支持上下选择、Tab 补全、
  Enter 提交所选命令、Esc 收起。
- Thinking/Responding/工具活动及计时只占输入框上方一行；footer 保留模型、
  路径和权限模式，窄窗口优先保留权限模式。
- 滚轮和 PageUp/PageDown 浏览记录；折行按屏幕行滚动。向上翻阅后新输出
  不抢走当前位置；Ctrl+End 或提交输入恢复跟随底部。
- 权限审批的完整命令和 diff 使用与独立模式相同的预览构建器，操作按钮默认拒绝。
- 审批使用细分隔线、操作标题和编号选项；1/2/3 快选，选择会话授权时明确显示
  所有同名工具调用的范围。审批出现时清除旧选区，以显示当前操作预览。
- 拖动输出建立高亮选区，松手自动复制；Esc 清除选区。选择期间固定内容快照，
  仍可滚动浏览；窗口宽度变化时清除旧选区。macOS 优先使用 pbcopy，其他平台
  尝试本地剪贴板工具，不可用时使用 OSC 52 并明确显示这是终端复制请求。
- Read/List 等工具使用简短操作行，模型说明独立显示。编辑成功直接展示完整
  diff；模型协议重试独立显示，不挂在前一个工具的失败记录下。
- 流式答案按完整 Markdown 块追加，完成时只写剩余内容。
- 单次任务的异常不应杀死队列消费者；UI 关闭后新的审批请求立即拒绝。
- UI 将重绘限制为最多约 30 FPS；spinner 的活动刷新保持 10 Hz。
- 窗口缩放时从原始内容重新排版已输出的 Markdown、表格和工具记录；
  翻阅历史时尽量保持在同一个内容块内。
- 有输出选区时 Ctrl+C 复制选区；无选区且忙碌时取消当前任务并保留草稿；空闲时清空输入。已排队任务继续
  顺序执行。取消是独立的 `run_cancelled` 事件，不作为工具失败重试。
- 取消会打断限流等待、关闭已连接的模型 HTTP socket，并终止 Shell 进程组；
  等待权限时同时解除审批等待。模型取消后到达的数据不能再写入 UI。

## 验证与限制

`tests/test_ui.py` 覆盖既有布局、流式不重复、工具记录、审批和输入隔离。
`tests/test_ui_interactions.py` 覆盖折行滚动锚点、窄窗口 footer、异常后继续处理
队列、关闭后权限请求、完整审批预览、真实按键输入、逐字节 Unicode 解码。

`tests/test_cancellation.py` 使用真实本地 HTTP 服务验证响应头/响应体等待的
取消，验证限流等待、POSIX Shell 子进程清理、迟到内容丢弃及后续任务继续执行。
`tests/test_selection.py` 覆盖中文与跨行选区、选择期间持续输出、窗口缩放和
剪贴板路由。系统剪贴板测试使用模拟调用，真实终端复制仍需人工验收。

长会话尚未做虚拟化或记录容量限制。`/verbose` 影响后续输出，不会重新展开
已提交的历史记录。取消不会撤销已经完成的文件修改；自行脱离进程组的后台
程序不属于普通 Shell 进程组清理的保证范围。Windows 使用 `taskkill /T /F`，
需在 Windows 环境另外验收。操作系统 DNS/连接建立过程可能不能立即中断：
调用方会立即结束等待，后台 I/O 最迟在网络超时后退出；连接建立后检查取消
  状态，不再发送后续请求或交付结果。取消本地连接不能保证服务商立即停止计费。

人工验收应包含：中文/emoji 长回答、长命令审批、保留输入草稿、任务执行中
滚动、调整终端大小、连续提交任务，以及 macOS 终端的触摸板滚动体验。
